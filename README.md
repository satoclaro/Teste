# Configuração eMTA / ONT 192.168.0.1 — Claro Telecom

Ferramenta web em arquivo único (`index.html`) para técnicos de campo da **Claro**, reunindo:
- **4 campos de cópia rápida no topo** (Usuário 192.168.0.1, Senha 192.168.0.1, Usuário Wi-Fi 2.4 GHz / 5 GHz com SSID `CLARO_` ou `NET_`, e Senha Wi-Fi) com cópia automática ao tocar.
- **Câmera (`Html5Qrcode` + mira/foco/lanterna + OCR/Barcode + Foto/Arquivo)** para leitura de etiquetas de **eMTA e ONT**.
- **Exibição formatada no fim da página** (Modelo, Fabricante, Input, Fabr., S/N, CM MAC, eMTA MAC, Usuário/Senha `192.168.0.1`, SSIDs 2.4 GHz e 5 GHz e Senha Wi-Fi) com cópia ao tocar.
- **Arquivamento local e exportação/importação em CSV, JSON e PDF**.
