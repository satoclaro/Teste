# Configuração eMTA / ONT 192.168.0.1 — Claro / NET

Ferramenta web em arquivo único (`index.html`) baseada em **captura de foto em alta resolução** com extração OCR multi-passagem:
- **Captura de foto**: botão para câmera web em alta resolução ou câmera nativa (`Tirar Foto Direto`), exibindo prévia da foto capturada e barra de progresso das 4 passagens de extração.
- **Extração reforçada de credenciais**:
  - **Usuário e Senha `192.168.0.1`**
  - **Redes Wi-Fi começando sempre com `CLARO_` ou `NET_`** (2.4 GHz e 5 GHz) e **Senha Wi-Fi**
  - **DOCSIS**, Modelo, Fabricante, Input, Fabr., S/N, CM MAC e eMTA MAC
- **4 campos de cópia rápida no topo** com destaque visual caso algum campo não tenha sido identificado na foto.
- **Arquivamento local e exportação/importação em CSV, JSON e PDF**.
- **Rodapé estático**: `Criado por: Fernando Sato - Versão 1.1 - 24/11/2026 20:37`.
