# Configuração eMTA / ONT 192.168.0.1 — Claro

Ferramenta web em arquivo único (`index.html`) para equipamentos exclusivamente da **Claro**, reunindo:
- **4 campos de cópia rápida no topo** (Usuário 192.168.0.1, Senha 192.168.0.1, Usuário Wi-Fi 2.4 GHz / 5 GHz com SSID `CLARO_`, e Senha Wi-Fi) com cópia automática ao tocar.
- **Câmera (`Html5Qrcode` + mira/foco/lanterna + OCR/Barcode + Foto/Arquivo)** para leitura de etiquetas de **eMTA e ONT da Claro**.
- **Exibição formatada no fim da página** com campo **DOCSIS**, além de Modelo, Fabricante, Input, Fabr., S/N, CM MAC, eMTA MAC, Usuário/Senha `192.168.0.1`, SSIDs `CLARO_` (2.4 GHz e 5 GHz) e Senha Wi-Fi.
- **Arquivamento local e exportação/importação em CSV, JSON e PDF**.
